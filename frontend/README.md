# Executor Balancer Frontend

Frontend-контур мониторинга и объяснимости распределения заявок. Проект реализован на Vite, React и TypeScript и по умолчанию подключается к реальному backend API.

## Запуск

```bash
npm install
npm run dev
```

Проверка типов и production-сборка:

```bash
npm run typecheck
npm run build
npm test
```

## Источник данных

При локальном запуске Vite проксирует `/api` на backend `http://localhost:8090`. Значение `VITE_DATA_SOURCE=mock` можно указать в `.env.local` только для автономной демонстрации; `api` используется по умолчанию. При ошибке API автоматического переключения на моки нет.

В общем контуре frontend запускается командой `docker compose up --build -d` из корня репозитория и доступен по адресу `http://localhost:8080`.

Основные маршруты:

- `/dashboard` — метрики, графики нагрузки и последние назначения;
- `/orders` — список и фильтры заявок;
- `/orders/:id` — заявка, назначение и Decision Trace;
- `/executors` — нагрузка, лимиты и управление активностью исполнителей;
- `/rules` — список правил, включение/выключение и Test Rule.

Dashboard поддерживает период, группировку, mock-сценарии и экспорт CSV/XLSX. Фильтры Orders синхронизируются с URL, поэтому отфильтрованное представление можно сохранить ссылкой.
